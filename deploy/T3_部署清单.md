# T3 语义层部署清单（Workbench 网页 RDP 手动执行）

> 目的：把语义层代码（semantic/ 目录、语义目录页、financials）部署到线上 Demo。
> 本次只走代码，不覆盖服务器的数据与密钥。
> 凭据：Administrator + `deploy/ecs.local.env` 里的密码

---

## 1. 备份现状（2 分钟）

打开 Workbench PowerShell（开始菜单搜 PowerShell），逐条贴：

```powershell
robocopy C:\quantinsight\streamlit_app\data C:\qi_data_backup_1118 /E
copy C:\quantinsight\streamlit_app\.streamlit\secrets.toml C:\secrets.toml.bak
```

## 2. 下载代码 tarball

```powershell
curl.exe -L -o C:\qi_main.tar.gz https://codeload.github.com/yigenfeng0707-netizen/quantinsight-pro/tar.gz/refs/heads/main
tar -xzf C:\qi_main.tar.gz -C C:\
dir C:\quantinsight-pro-main
```

- 若 GitHub 慢/超时：本地 `D:\AFAC2026金融智能创新大赛\quantinsight-deploy\..\..\qi_main.tar.gz`（本地已下好）用 Workbench「文件传输」传到 C:\ 再解压
- 解压后确认 `C:\quantinsight-pro-main\streamlit_app\semantic\` 存在（里面应有 ontology.ttl 等 4 个 ttl + py 文件）

## 3. 覆盖代码（保留数据/密钥）

```powershell
robocopy C:\quantinsight-pro-main C:\quantinsight /E /XD data .streamlit __pycache__ .pytest_cache /XF *.db *.toml
```

> `/XD` 排除 data 等，`/XF` 排除 db/toml —— secrets.toml、qi_data.db、users.db 全部保持服务器现状。

确认：

```powershell
dir C:\quantinsight\streamlit_app\semantic\
dir C:\quantinsight\streamlit_app\features\semantic_browser.py
```

## 4. 安装 rdflib

```powershell
C:\Miniconda3\Scripts\pip.exe install "rdflib>=7.0.0"
```

纯 Python 包，约 10 秒。装完验证：

```powershell
C:\Miniconda3\python.exe -c "import rdflib; print(rdflib.__version__)"
```

## 5. 拉财报入库（核心 51 只，约 1 分钟）

```powershell
C:\Miniconda3\python.exe C:\quantinsight\scripts\build_financials.py
```

- 看到末行 `完成：写入 N 行，失败 M 只` 即可（个别标的无数据属正常）
- **若失败**（akshare 接口变动）：不影响应用运行，财务接地自动退化为空，其余功能照常

## 6. 重启应用

```powershell
taskkill /F /IM python.exe
schtasks /run /tn QuantInsight
Start-Sleep 25
curl.exe http://localhost/_stcore/health
```

输出 `ok` 即服务起来。
